# 儿童象棋

专门陪 5 岁孩子下棋的中国象棋网页应用。

它追求的不是最强棋力，而是“有逻辑，但不完美”：电脑会遵守完整规则、吃子、将军和保护重要棋子，也会像初学几年的孩子一样偶尔漏棋。孩子可以无限悔棋，得到简短但不直接公布答案的提示，并在关闭浏览器后继续上一盘。

## 已实现

- 完整中国象棋棋盘与红黑双方
- 车、马、炮、象、士、将、兵的合法走法
- 马腿、象眼、炮架、将帅照面、将军、应将和将死
- 三档儿童友好电脑难度
- 轻量开局习惯：屏风马、中炮、起马和飞象布阵
- 无限悔棋、轻提示和重新开始
- 浏览器本地自动保存
- iPad、iPhone、Android、Mac 和 Windows 响应式界面
- Safari 添加到主屏幕与离线缓存

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

构建检查：

```bash
npm run build
```

所有棋局数据只保存在当前设备的浏览器中，不需要账号、服务器或数据库。
